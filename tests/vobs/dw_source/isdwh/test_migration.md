### Test Case 2.1: Date Boundary Filtering (`LAST_UPDATE` Range)
* **Purpose**: Verify that the PySpark job correctly filters the source view using the calculated date boundaries (`first_day` inclusive, `last_day_plus_1` exclusive).
* **Setup**:
  Create a mock Spark DataFrame containing records with `LAST_UPDATE` values exactly on, inside, and outside the boundary dates.
* **Action**:
  Execute the filtering logic inside a pytest environment.
  
  ```python
  from pyspark.sql import SparkSession
  from pyspark.sql.types import StructType, StructField, StringType
  from vobs.dw_source.isdwh.agent_ads_lookup import run_extraction_pipeline
  import argparse
  
  def test_date_boundary_filtering(spark_session):
      schema = StructType([
          StructField("AGENT_ID", StringType(), True),
          StructField("LAST_UPDATE", StringType(), True)
      ])
      
      # Boundary: '2023-07-09' to '2023-10-02'
      data = [
          ("A001", "2023-07-08"),  # Out (Before)
          ("A002", "2023-07-09"),  # In (Exact Lower Boundary)
          ("A003", "2023-08-15"),  # In (Middle)
          ("A004", "2023-10-01"),  # In (Exact Upper Boundary - 1 day)
          ("A005", "2023-10-02"),  # Out (Exact Upper Boundary)
          ("A006", "2023-10-03")   # Out (After)
      ]
      
      df = spark_session.createDataFrame(data, schema)
      df.createOrReplaceTempView("DWH_VI_S_SDM_AGENT_ADS")
      
      # Mock arguments
      args = argparse.Namespace(
          output_bucket="test-bucket",
          output_file="test_output.txt",
          backlook_days=84,
          project_prefix="BHB_CCM_PROC",
          first_day="2023-07-09",
          last_day_plus_1="2023-10-02",
          gcp_project="test-project"
      )
      
      # Apply filtering logic
      processed_df = df.filter(
          (df["LAST_UPDATE"] >= args.first_day) &
          (df["LAST_UPDATE"] < args.last_day_plus_1)
      )
      
      results = [row.AGENT_ID for row in processed_df.collect()]
      
      assert "A002" in results
      assert "A003" in results
      assert "A004" in results
      assert "A001" not in results
      assert "A005" not in results
      assert "A006" not in results
  ```
* **Pass/Fail Criterion**: The test passes if only records `A002`, `A003`, and `A004` are retained. It fails if any out-of-bounds records are included or if boundary records are missing.
