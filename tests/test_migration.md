The following test cases are designed to cover output parity, transformation correctness, external system replacements (logging), and data quality/schema assertions. They assume a `pytest` framework for orchestration and BigQuery SQL for assertions.

**Assumptions for Test Setup:**

*   **BigQuery Environment:** A BigQuery project (`project`) and dataset (`dataset`) are set up for the migrated stored procedures and target tables.
*   **Source Data:** A separate BigQuery project (`source_project`) and dataset (`source_dataset`) exist, containing mock data for all source tables (`bpd_ta_means_of_payment`, `bpd_ta_bank`, `bpd_ta_bank_international`, `sof_ta_e_regulierer`, `sof_ta_e_reach_re`, `sof_ta_e_business_re`, `dwh_vi_s_ibasisprodukt`). *   **Golden Data:** For output parity tests, a "golden" dataset (e.g., CSV files or temporary BigQuery tables) is generated by running the *legacy* `r_ausd_rechempf.ksh` script against the *same mock source data*. This is crucial for direct comparison.
