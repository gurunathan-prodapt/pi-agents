*   **Purpose:** To verify that the Cloud Composer DAG correctly handles expected failures (e.g., BigQuery SQL errors, GCS export issues) and provides adequate logging and monitoring.
*   **Setup:**

*   **Action:**
    1.  **Scenario A: BigQuery SQL failure.**

        *   Monitor the DAG run in the Airflow UI and check Cloud Logging for the `prepare_nna_data` task.
    2.  **Scenario B: GCS Export failure.**

        *   Trigger the DAG.
        *   Monitor the DAG run in the Airflow UI and check Cloud Logging for the `export_nna_data_to_gcs` task.

Downstream tasks dependent on `prepare_nna_data` (like `export_nna_data_to_gcs`) are skipped or marked `upstream_failed`.
