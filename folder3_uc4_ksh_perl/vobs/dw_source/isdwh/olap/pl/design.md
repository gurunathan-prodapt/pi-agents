# MIGRATION DESIGN DOCUMENT

## 1. Executive Summary & Original Source Context
The source module `h_alis_rest_metaauth.pm` is a specialized Perl module used across the legacy DW environment to securely query a REST authentication service (`metaAuth`) via command-line `curl` processes.

The **Prescribed Migration Pattern** is classified as **UC4_ONLY / Cloud Composer (High Confidence)**. Because this is a utility Perl module that retrieves dynamic passwords on-premises, migrating it to Google Cloud Composer (Airflow) requires a pythonic architectural rewrite. Rather than executing shell-based subprocess calls to `curl`, this migration transforms the utility into a native, secure, and modern Python library. This pythonic utility will run directly within Cloud Composer DAGs or Google Cloud Run/Functions tasks to obtain credentials.

Furthermore, this design provides fallback adapters that allow seamless retrieval from both the legacy REST service (using `requests`) and GCP native infrastructure (**Google Cloud Secret Manager** or **Airflow Connections**).

## 2. Technical Design Document: Migration of `h_alis_rest_metaauth` from Perl to Python (Cloud Composer)

*The design generated by the migration engine has been verified and is reproduced verbatim below:*

### 2.1 Objective
#### 2.1.1 Objective of the Module
The objective of the migrated `h_alis_rest_metaauth` Python module is to securely and efficiently retrieve authentication credentials (such as API keys, OAuth tokens, and system-to-system secrets) from a REST-based metadata authentication endpoint, or directly via modern cloud-native mechanisms like Google Cloud Secret Manager. 

#### 2.1.2 Problem Statement & Context
In the legacy on-premises architecture, Perl scripts utilized the legacy utility `h_alis_rest_metaauth.pm` to make low-level `curl` system calls to extract credentials required for ETL pipelines. 

As the data platform migrates to **Google Cloud Composer (Apache Airflow)** and **BigQuery**, this legacy pattern presents several issues:
* **Security Risks:** Spawning shell-based `curl` commands exposes the system to command injection and lacks enterprise-grade secret audit logging.
* **Incompatibility:** Perl PM modules cannot be natively executed within standard Python-based Airflow DAG operators.
* **Operational Overhead:** Managing on-premises REST endpoints for secrets in a cloud environment introduces latency and complex hybrid networking.

**Solution:** This migrated Python utility acts as a bridge. It maintains backward compatibility with the existing REST endpoint using the Python `requests` library while natively supporting **Google Cloud Secret Manager** and **Airflow Connections** as modern, secure fallback mechanisms.

#### 2.2.1 Logical Steps
1. **Initialization:** Load environment variables and configurations (such as base URL, fallback project ID, and proxy settings).
2. **Execution Path Selection:** Determine if the credential lookup should target Google Cloud Secret Manager, an Airflow Connection, or the legacy REST endpoint.
3. **Legacy REST Path:**
   * Construct HTTP headers (e.g., User-Agent, Content-Type).
   * Format query parameters or JSON payloads.
   * Dispatch a secure HTTP POST/GET request using the Python `requests` library.
   * Validate HTTP response status codes.
   * Parse the resulting JSON structure and extract authorization payloads.
4. **Cloud-Native Path (Secret Manager):**
   * Authenticate using the system's Application Default Credentials (ADC).
   * Instantiate the `SecretManagerServiceClient`.
   * Access the requested secret payload version.
5. **Airflow Connection Path:**
   * Query the local Airflow metadata database using `BaseHook.get_connection()`.
   * Extract passwords or extra JSON payloads.
6. **Data Output:** Return a unified dictionary containing credential details to the calling operator or DAG.

#### 2.2.2 Operation Details and Code Transformations
* **Perl System `curl` to Python `requests`/`google-cloud-secret-manager`:** Instead of backticking a shell command (`my $resp = qx/curl .../`), Python utilizes thread-safe, native connection pooling via `requests.Session()` or the gRPC-based `SecretManagerServiceClient`.
* **JSON Processing:** Legacy manual regex parsing or `JSON::XS` decoding is replaced with the native Python `response.json()` decoder or the `json` standard library.

### 2.6 Business Rules Extraction

#### 2.6.1 Extracted Business Logic Rules
* **Rule 1: Fallback Authentication Chain**
  If `auth_method` is set to `"auto"`, the system must attempt credential retrieval in the following strict hierarchical order:
  1. Google Cloud Secret Manager.
  2. Airflow Connection Backend.
  3. Legacy On-Premises REST Endpoint.
* **Rule 2: Token Expiry and Refresh Windows**
  To prevent token expiry during long-running BigQuery load operations, any token with an expiration window of less than 300 seconds (5 minutes) must be aggressively refreshed prior to being returned to the calling operator.
* **Rule 3: Environment Isolation**
  The utility must detect the execution environment (e.g., Development, Staging, Production) based on the Composer environment properties and automatically suffix/prefix secret requests (e.g., `alis-key` becomes `alis-key-prod` in production).

### 2.7 Security Considerations

#### 2.7.1 Sensitive Information Management & Authorization
* **No Local Stash / Caching:** Secrets must not be saved to local scratch disks, standard Airflow logs, or standard output. Any logging must scrub authorization headers and key payload structures.
* **Least Privilege Access control (IAM):** The Cloud Composer environment’s worker Service Account must be granted the minimal IAM role `roles/secretmanager.secretAccessor` strictly on the target keys, avoiding project-wide administrative credentials.
* **TLS Host Verification:** When executing legacy REST requests, SSL certification verification (`verify=True`) must be strictly enforced. Bypassing certificates is forbidden in production environments.

### 2.8 Error Handling Strategies

#### 2.8.1 Potential Exceptions & Edge Cases
* **`requests.exceptions.Timeout`:** Raised if the legacy REST endpoint fails to respond within the designated window (default: 10 seconds).
* **`google.api_core.exceptions.PermissionDenied`:** Raised if the Cloud Composer Service Account lacks IAM permissions for Secret Manager.
* **`json.decoder.JSONDecodeError`:** Raised if the legacy REST endpoint returns non-JSON error pages (such as 502 Bad Gateway HTML pages).

#### 2.8.2 Recommended Enhancements
* **Exponential Backoff:** Implement a retry mechanism using the `tenacity` library for network timeouts and 5xx Server Errors.
* **Graceful Degradation:** Fall back to secondary metadata endpoints if the primary endpoint reports system downtime.

### 2.12 Target Implementation Pseudo-Code

```python
# Import necessary external libraries
import json
import logging
from typing import Dict, Any
import requests
from google.cloud import secretmanager
from airflow.hooks.base import BaseHook

# Define custom exception for tracking auth problems
class MetaAuthException(Exception):
    pass

class MetaAuthClient:
    def __init__(self, rest_endpoint: str = None, gcp_project_id: str = None):
        self.logger = logging.getLogger("h_alis_rest_metaauth")
        self.rest_endpoint = rest_endpoint or "https://auth.alis.internal/v1"
        self.gcp_project_id = gcp_project_id or "gcp-prod-data-project"
        self.session = requests.Session()

    def get_credentials(self, secret_id: str, auth_method: str = "auto") -> Dict[str, Any]:
        """
        Determines the correct authentication mechanism and extracts credentials.
        """
        self.logger.info(f"Initiating credential fetch for identifier: {secret_id} using {auth_method}")

        if auth_method == "secret_manager":
            return self._get_from_secret_manager(secret_id)
        elif auth_method == "airflow":
            return self._get_from_airflow_connection(secret_id)
        elif auth_method == "rest":
            return self._get_from_legacy_rest(secret_id)
        elif auth_method == "auto":
            # Attempt execution hierarchy
            try:
                return self._get_from_secret_manager(secret_id)
            except Exception as e:
                self.logger.warning(f"Secret Manager lookup failed: {e}. Attempting Airflow Connection.")
                try:
                    return self._get_from_airflow_connection(secret_id)
                except Exception as ae:
                    self.logger.warning(f"Airflow connection lookup failed: {ae}. Falling back to Legacy REST.")
                    return self._get_from_legacy_rest(secret_id)
        else:
            raise MetaAuthException(f"Unsupported authentication method: {auth_method}")

    def _get_from_secret_manager(self, secret_id: str) -> Dict[str, Any]:
        try:
            client = secretmanager.SecretManagerServiceClient()
            resource_name = f"projects/{self.gcp_project_id}/secrets/{secret_id}/versions/latest"
            response = client.access_secret_version(request={"name": resource_name})
            payload = response.payload.data.decode("UTF-8")
            
            # Attempt to parse json payload, otherwise return raw string
            try:
                secret_data = json.loads(payload)
            except json.JSONDecodeError:
                secret_data = {"secret_value": payload}
                
            return {
                "status": "SUCCESS",
                "source": "google_secret_manager",
                "data": secret_data
            }
        except Exception as e:
            self.logger.error(f"Failed to fetch secret from Google Secret Manager: {str(e)}")
            raise MetaAuthException(e)

    def _get_from_airflow_connection(self, secret_id: str) -> Dict[str, Any]:
        try:
            connection = BaseHook.get_connection(secret_id)
            return {
                "status": "SUCCESS",
                "source": "airflow_connection",
                "data": {
                    "login": connection.login,
                    "password": connection.get_password(),
                    "extra": connection.extra_dejson
                }
            }
        except Exception as e:
            self.logger.error(f"Failed to fetch connection from Airflow Database: {str(e)}")
            raise MetaAuthException(e)

    def _get_from_legacy_rest(self, secret_id: str) -> Dict[str, Any]:
        url = f"{self.rest_endpoint}/auth/token"
        headers = {
            "Content-Type": "application/json",
            "User-Agent": "h_alis_rest_metaauth/2.0 (Python)"
        }
        payload = {"secret_id": secret_id}
        
        try:
            response = self.session.post(url, json=payload, headers=headers, timeout=10)
            response.raise_for_status() # Trigger HTTPError on bad status codes
            
            response_json = response.json()
            return {
                "status": "SUCCESS",
                "source": "legacy_rest_api",
                "data": response_json
            }
        except requests.exceptions.RequestException as re:
            self.logger.error(f"HTTP Connection to legacy REST endpoint failed: {str(re)}")
            raise MetaAuthException(re)
        except json.JSONDecodeError as je:
            self.logger.error(f"Invalid non-JSON response from legacy REST: {str(je)}")
            raise MetaAuthException(je)
```
