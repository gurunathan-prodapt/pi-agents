DECLARE v_datum STRING DEFAULT (
  SELECT IFNULL(FORMAT_DATE('%Y%m%d', MAX(DATE(m.timecreated))), '19000101')

-- Step02: insert valid MSISDN records

  cn1.bpri_com_id,

## 6. Risks, Optimization, & Manual Review Steps

1.  **Database Link Migration:** In the legacy code, `pds$ta_callnumber` was queried via DB link `@pcrs1`. Ensure that the ingestion pipeline from the source database continuously populates `pds.ta_callnumber` in BigQuery before this pipeline runs.
2.  **Date/Time Formatting:** BigQuery requires strict formats for date parsing. The variable `v_datum` from `dwtk_meldungen` relies on `timecreated` converting correctly. Verification of the historical datatypes during schema build in BigQuery is highly recommended.
3.  **Parallel Hint Ignored:** The Oracle optimizer hint `/*+ full(cn1) parallel(cn1,4) */` is ignored in BigQuery since BigQuery automatically scales compute power dynamically for scanning large tables. No alternative configuration is required.
