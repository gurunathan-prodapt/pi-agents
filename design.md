## 1. Executive Summary & Migration Approach

The source component is a KornShell (`ksh`) library module (`h_alis_meldungen.ksh`) providing a standard, centralized framework for operational metadata logging, job tracking, error routing, and audit telemetry in a Data Warehouse (DWH) environment. It translates local script variables and execution boundaries into transactional database updates against an Oracle package (`CCR$VS_MELDUNG`) using embedded `sqlplus` calls.

Since the target environment is **BigQuery**, we leverage **BigQuery Standard SQL Stored Procedures** to maintain modularity, encapsulation, and backward-compatible operational signatures. 
* Direct PL/SQL package calls are mapped to BigQuery `CALL` commands referencing equivalent metadata stored procedures.
* Parameter validation exit codes (e.g., `exit 2`) are mapped to BQ `ERROR()` statements to halt operational scripts on validation failures.
* Dynamic logging filenames generated by local shell system calls (`date`) are calculated natively inside BQ procedures using formatting routines (`FORMAT_DATETIME`).
