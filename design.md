# Migration Design — DW.BERT_AUSD_BP_TA_TARIFOPTION

## 1. Purpose & Scope

This job, identified as `DW.BERT_AUSD_BP_TA_TARIFOPTION`, is responsible for the preparation and processing of "instantiated base products," specifically related to tariff options for the BERT system. The core function involves extracting, transforming, and loading data to define and populate `sof$ta_bpr_opt_filter` and `sof$ta_tarifoption` tables. It orchestrates shell scripts and an Oracle SQL script to achieve this data preparation, which is crucial for downstream reporting or analysis within the BERT environment. The scope of this migration is to re-platform this entire workflow from its current UC4/KornShell/Oracle environment to Google Cloud's BigQuery for data processing and Airflow for orchestration.
